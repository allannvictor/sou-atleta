## Notas do ambiente

- O `gh` nesta máquina não acessa a API GraphQL (`gh issue view`, `gh pr view` falham com 403). Use `gh api repos/...` (REST) ou as ferramentas do GitHub da sessão. `gh run list` e `gh run view --log-failed` funcionam.
- Dois agentes não podem usar a mesma pasta nem a mesma branch. Para trabalho em paralelo, o dono autoriza uma branch nova, e o agente roda em worktree (`.claude/worktrees/`, que **não** está no `.gitignore`: remover a worktree depois do push e nunca usar `git add .`).
- Dois PRs que mexem no `pnpm-lock.yaml` podem passar sozinhos e quebrar juntos (PR #33). Depois de mesclar um, atualizar o outro com a `main` antes de mesclar.
- O Playwright desta máquina precisa de `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` apontando para o Chromium em `/opt/pw-browsers` (o `pnpm check` falha nos e2e sem isso). Não rode `playwright install`.
- Pushes de clones rasos: `git -c push.negotiate=true push`.
- O plano do Claude do dono atingiu o limite de 5 horas duas vezes nesta sessão, com os agentes em segundo plano. O trabalho não se perde: o agente é retomado com uma mensagem depois do reinício. Para economizar, a sessão principal faz sozinha correções mecânicas pequenas (como o PR #33) e junta os achados das revisões numa rodada só.
- O `/app` não abre nos testes de interface sem JWT válido. Os prints do quadro são gerados a partir do componente real com o CSS real.
